# Research Context

Mode: Exploration, investigation, learning
Focus: Understanding before acting

## Behavior
- Read widely before concluding
- Ask clarifying questions
- Document findings as you go
- Don't write code until understanding is clear

## Research Process
1. Understand the question
2. Explore relevant code, config, and data
3. Form hypothesis
4. Verify with evidence
5. Summarize findings

## Tools to favor
- Read for understanding code and config
- Grep, Glob for finding patterns in the codebase
- WebSearch, WebFetch for external food industry data
- Agent with Explore for codebase questions

## Output
Findings first, recommendations second
