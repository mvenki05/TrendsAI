What needs the key vs. what doesn't

🔑 Needs a key (the AI calls)

  • Upload a report — date + taxonomy + normalize
  • Synthesize megatrends
  • Discover from the web
  • Match ingredients to Tyson products

✅ Works without a key

  • Google Trends (pytrends) & Reddit (PRAW)
  • All BigQuery reads/writes
  • Dashboard pages, charts, navigation
  • File text parsing (only the analysis needs Claude)

All AI calls route through one function — src/common.py · complete_json() — so one credential fixes every button at once. The UI buttons spawn a detached Python job and return immediately, so a missing key shows as an endless spinner, not an error.

Getting a direct key (if going that route)

  1. Ask the team that issued your LITELLM_API_KEY (they administer Tyson's Anthropic access) for a direct key — or whether direct access is permitted.
  2. Or sign in to platform.claude.com with Tyson SSO → if you have a workspace → Settings → API Keys → Create Key.
  3. Caveat: Tyson access may be AWS Bedrock-backed → then it's IAM credentials + the AnthropicBedrock client, not an sk-ant- key. Confirm with them.
